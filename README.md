# Mostafa Tavassoli

**Backend Software Engineer**

I build backend services and APIs with Java, Kotlin, and C#/.NET. My work focuses on system reliability, database performance, integration testing, and security testing of AI agents.

## Featured projects

**[Infrastructure Agent Conformance](https://github.com/mosTavassoli/infra-agent-conformance)**

An open-source test harness that evaluates whether AI agents respect read-only boundaries while investigating Kubernetes failures. It checks for forbidden Kubernetes operations and disclosure of synthetic secrets in sandboxed runs.

**[StreamJack](https://github.com/mosTavassoli/streamjack)**

A security and utility test harness for event-driven AI agents (Java, Quarkus, LangChain4j). It tests whether an agent can be hijacked through a Kafka message.
